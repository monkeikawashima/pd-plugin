# ジャーニー

**1ペルソナ × 1主要タスク = 1本。** 系統をまたいだ「代表的な流れ」を1本にまとめない。

---

## <ペルソナの呼称> / <主要タスク名>

| 項目 | 値 |
|---|---|
| 対象ペルソナ | <呼称>（確信度: 実証 / 作業仮説） |
| 主要タスク時間 | <kpi.md の定義と同じ語> |
| ベースライン | <実測値> / **未取得** |

### 分解式

**この右辺は `ux-measurement` の構成要素と同一物。** 別々に管理しない。

```
<主要タスク時間> = <ステップ1> + <ステップ2> + <ステップ3>
```

### ステップ

| # | ステップ | 担う画面・接点 | 触るオブジェクト | ストーリー | 根拠 | 所要時間 | 詰まり・離脱 |
|---|---|---|---|---|---|---|---|
| 1 | | | | US-xx | VOICE-xxx | **未取得** | 未観測 |
| 2 | | | | US-yy | **一次情報なし** | **未取得** | [推測] … |
| 3 | | | | | | | |

> - 根拠が0件のステップは「**一次情報なし**」と書く。その設計は**デザイナー起案**。
> - 所要時間は実測値か「**未取得**」。それらしい数字を置かない。
> - 詰まりは、観測された事実か `[推測]` を付けた解釈のどちらか。

### 裏側（**任意**。不要なら節ごと削除する）

利用者が待っている間、裏で動いている人・処理・待ち。**待ちは利用者の時間を消費している。**

| # | 表側の接点 | 裏側の処理 | 待ちの所要時間 |
|---|---|---|---|
| 1 | | | **未取得** |

### 空白の集計（**省略しない**）

| 空白 | 件数 | 意味 |
|---|---|---|
| 根拠が一次情報なし | | この区間の設計はデザイナー起案 |
| 所要時間が未取得 | | 改善したと**言えない**区間 |
| 担う画面が未設計 | | 骨格層への申し送り |

> 埋まっているところだけを見せると、全体が検証済みに見える。
