# ux-update-cascade — 更新の連鎖

## 役割分界（重複させない）

| このスキルがやること | やらないこと（担当スキル） |
|---|---|
| 上流変更の起点の特定 | 検証の実施設計（`ux-validation-planner`） |
| 下流への影響の洗い出し | 計測（`ux-measurement`） |
| `要再検証` のマーキング | 個別の決定記録（`ux-decision-record`） |
| ステータス差し戻しの**提案** | ステータス変更の**実行**（人間の合意事項） |

**前提**: spec は「その時点の合意を固定して下流を進めるためのもの」。**更新しないという意味ではない。**
連鎖は**一方向（上→下）**、フィードバックは双方向。

## トリガー

| # | トリガー | 再検証するもの |
|---|---|---|
| A | 新しい顧客・利用者層が入る | 理想顧客像の定義 / 「このドメインだから効く」という前提 / 主要な入力項目・情報項目の設計 |
| B | ユーザー検証の結果が出る | 反証された仮説と、それに依存する下流すべて |
| C | 計測データが揃う | ベースライン前提で書かれた判断 |
| D | 顧客ボイスの傾向が変わる | 原則の優先順位 / 未解消 pain の分布 |
| E | ペルソナが増減する・確信度が変わる | そのペルソナのジャーニー / 主要タスク時間の定義 / 対応するストーリー |
| F | ジャーニーのステップが変わる | 主要タスク時間の構成要素 / 担う画面の仕様 / 取得中のベースライン |
| G | トークンの値・命名が変わる | 使用している画面仕様 / コントラスト検算の結果 / 逸脱一覧 |

## 手順

### 1. 起点の spec を特定する

何が変わったのか、どの層のどのファイルか。

### 2. 参照している下流を洗い出す

| 探す場所 | 何を |
|---|---|
| `pd/specs/` の下位層 | 起点を前提にしている記述 |
| `pd/specs/02-requirements/user-stories.md` | 原則・オブジェクトが変わったストーリー |
| `pd/specs/01-strategy/personas.md` | 根拠件数・確信度が変わった像 |
| `pd/specs/02-requirements/journeys.md` | 前提が変わったステップと分解式 |
| `pd/specs/04-skeleton/layout-hypotheses.md` | 前提が変わった等価案 |
| `pd/specs/04-skeleton/screens/` | 前提が変わった画面仕様 |
| `pd/specs/05-surface/design-tokens.md` | 値が変わったトークンと逸脱 |
| `pd/decisions/` | 根拠が崩れた UXDR |
| 実装 | 該当する画面・機能 |

### 3. `要再検証` を付ける

影響のある spec の frontmatter を `status: 要再検証` にする。

### 4. ステータス差し戻しを**提案する**

```
差し戻し候補: <spec> （合意済み → 要再検証）
理由: <起点の変更内容>
```

> **昇格・差し戻しの実行は人間の合意事項。** ここで停止する。

### 5. 変わらなかったことを記録する

> **連鎖で最も価値があるのは「変わらなかった」という記録。**
> 書かないと、次の人が同じ確認を繰り返す。

## 出力形式

```
■ トリガー: A / B / C / D / E / F / G
■ 起点: <spec とその変更内容>

■ 影響あり（要再検証）
   | 成果物 | 何が崩れるか | 対応 |
   |---|---|---|
   | pd/specs/… | … | 要再検証を付けた |

■ 影響なし（**確認済み。ここを空にしない**）
   | 成果物 | 確認した内容 | 結論 |
   |---|---|---|
   | pd/specs/… | … | 前提は維持される |

■ ステータス差し戻しの提案（実行は人間）
   <spec>: 合意済み → 要再検証

■ 次のアクション: <スキル名>
```

## 禁止

- 「影響なし」を書かずに終わる（次の人が同じ確認を繰り返す）
- ステータスの昇格・差し戻しを AI が実行する
- 起点を特定せずに広く `要再検証` を付ける（付けすぎると誰も見なくなる）
- 反証された仮説に依存する下流を放置する
