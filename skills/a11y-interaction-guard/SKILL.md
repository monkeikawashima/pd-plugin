# a11y-interaction-guard — 操作の下限

**`a11y-contrast-guard` と対になるスキル。** あちらは**値**（色）を計算し、こちらは**操作**を検査する。

**このレーンも上流の決着に依存しない。** 他層の合意を待たずに進められる。

## 役割分界（重複させない）

| このスキルがやること | やらないこと（担当スキル） |
|---|---|
| キーボード操作・フォーカス・読み上げ・寸法・動きの検査 | コントラスト比の検算（`a11y-contrast-guard`） |
| 下限を割っている箇所の特定 | 演出・見た目の最終決定（**DESIGN の領域**） |
| 逸脱表への追記 | UI 全体の評価（`ux-design-review`） |
| — | トークン台帳の所有（`design-token-keeper`） |
| — | 例外の記録（`ux-decision-record`） |

## 最初に読む

`skills/analyze/uiux/rules/04-accessibility.md`（下限の一覧と、検査のしかた）

## 検査項目

### 1. キーボードだけで完了できるか

**マウスを使わずに、その操作を最後まで通す。** 通らなければ下限割れ。

| 見るところ | 下限 |
|---|---|
| すべての操作要素に到達できるか | Tab / Shift+Tab で到達できる |
| 操作できるか | Enter / Space で実行、Esc で閉じる |
| **罠が無いか** | 入ったら出られない領域を作らない（モーダル・エディタ・埋め込み） |
| 独自のクリック領域 | `div` に `onClick` だけ付けた要素は**到達できない**。役割と操作を持たせる |

> ⚠️ **ホバーでしか出ない情報・操作は、キーボードにもタッチにも存在しない。**
> ホバーで出すなら、フォーカスでも同じものを出す。

### 2. フォーカスの順序と可視性

| 見るところ | 下限 |
|---|---|
| 順序 | 画面の読み順と一致する（見た目の並べ替えで順序が壊れていないか） |
| 可視性 | どこにあるか**常に**見える（コントラスト 3:1 以上） |
| 開いたとき | モーダル・ドロワーを開いたら、中へ移す |
| 閉じたとき | **開く操作をした要素へ戻す**（先頭へ飛ばさない） |
| 消えたとき | フォーカス中の要素を消す前に、行き先を決める |

> フォーカスリングを消してよいのは、**同等の `:focus-visible` 演出を置いた場合のみ。**

### 3. 読み上げに必要な情報があるか

| 見るところ | 下限 |
|---|---|
| アイコンだけのボタン | 名前を持つ（何をするかが読み上げられる） |
| 入力欄 | ラベルと結びついている（プレースホルダーはラベルの代わりにならない） |
| 画像 | 意味のある画像には説明、装飾なら空にする |
| 状態 | 開閉・選択・並び順・エラーが、見た目以外でも伝わる |
| **非同期の変化** | 読み込み完了・検索結果0件・保存成功が、**黙って**画面だけ変わらない |
| 見出し | 階層が飛んでいない（見た目の大きさで選ばない） |

> ⚠️ **「空振り」は読み上げでも空振りになりやすい。**
> 0件・該当なしを画面に出すだけで、通知が無いと利用者は待ち続ける。

### 4. 寸法

| 対象 | 下限 |
|---|---|
| タップターゲット | 44 × 44 px（モバイル） |
| 隣接する操作要素の間隔 | 誤タップが起きない距離を確保する |
| 文字の拡大 | 200% にしても内容と操作が失われない |

### 5. 動きの抑制を尊重するか

| 見るところ | 下限 |
|---|---|
| 大きな動き（視差・回転・拡大・自動スクロール） | 抑制設定を有効にしている利用者には出さない |
| 自動再生・自動切り替え | 止める手段を用意する |
| 点滅 | 1秒に3回を超えない |

## 手順

1. **対象を決める**（画面 / 部品 / 操作の流れ）
2. **上の5項目を順に当てる。** 実機・実装で確かめる。**記憶と見た目で判定しない**
3. 確かめられなかった項目は「**未確認**」と書く。**「たぶん大丈夫」を通さない**
4. 下限を割っている箇所を `pd/specs/05-surface/design-tokens.md` の逸脱表に**期限つきで**追記する
5. 例外として残す判断は `ux-decision-record` へ（棄却条件つき）

## 出力形式

```
■ 対象: <画面 / 部品>
■ 確認方法: 実機 / 実装コード / 未確認
■ キーボード: 完了できた / 到達できない箇所 <…> / 罠 <…>
■ フォーカス: 順序 OK・NG（<箇所>）/ 可視 OK・NG / 戻り先 OK・NG
■ 読み上げ: 名前の無い操作 <n> / 状態が伝わらない箇所 <n> / 非同期の無通知 <n>
■ 寸法: 44px 未満 <n> 箇所 / 拡大 200% で崩れる箇所 <n>
■ 動き: 抑制の尊重 有 / 無 / 該当なし
■ 未確認の項目: <一覧>（**空にしない。確かめていないことを確かめたことにしない**）
■ 記録先: pd/specs/05-surface/design-tokens.md（逸脱・期限つき）
```

## 禁止

- 実機・実装を見ずに「問題なし」と判定する
- ホバーでしか出ない情報・操作を残す
- フォーカスリングを、代わりを置かずに消す
- 「未確認」を空欄にする（確かめていないことは、確かめたことにならない）
- 期限の無い例外を逸脱表に残す
- このスキルが演出の最終形を決める（下限までが UX の領域。決めるのは DESIGN）
